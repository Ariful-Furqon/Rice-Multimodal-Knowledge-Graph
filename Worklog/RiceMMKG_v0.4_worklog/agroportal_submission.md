# Task 3.4 — AgroPortal submission package (template)

[AgroPortal](https://agroportal.lirmm.fr/) submission is a web form plus an
uploaded/URL-referenced ontology file. This is not a PR-based process like
w3id, so nothing is submitted automatically — this is prep material for
when you do it manually.
